## Architecture principles (not decisions, invariants)

- **Only the language model on the GPU.** STT and TTS on CPU. The language model is never unloaded (resident).
- **Single owned pipeline.** Only `llama-server` + CPU workers; no other VRAM consumer.
- **No unpredictable unloading.** No model swapping; no cold start.

## Considered and rejected alternatives

Options that came up during planning and were dropped (for the record; newest first):

| Topic | Considered | Why rejected |
|---|---|---|
| STT | Shrinking the encoder window with **`-ac` (audio context trimming)** | Looks fast (encode 10→3.2 s) but produces **repetition loops and corrupted transcripts** ("asistanım"→"hastanım"; a sentence 5× in an 11 s audio, 115 words in a 22 s audio). **Not safe** → decision #19 |
| STT | whisper `base` / `small` (for `<1 s` on CPU) | Fast but **weak Turkish accuracy** (base 0.84 s; small 2.5 s). Unacceptable for chat → open decision |
| STT | **Qwen3-ASR-1.7B** (and the `0.6B` fallback) | It had been chosen instead of whisper for a while; however, since 1.7B on CPU was ~4× real time it was risky for the `<1 s` target. Reverted to whisper.cpp with **#11**. Its Turkish/streaming advantage can be re-evaluated if needed |
| STT | whisper `large-v3` (full) | Slow on CPU; misses the `<1 s` target on its own (turbo was preferred) |
| LLM | Original `huihui-ai` **static** Q5_K_M | Works but imatrix (i1) quant gives better quality at the same size → #12 |
| LLM | Qwen 3.5 **27B** (MamidLabs MAX/FLASH) | Does not fit in 8 GB VRAM |
| TTS | **Fish Audio S2 Pro** (4.4B) | The most realistic and Turkish-capable, **but** Fish Audio Research License (non-commercial), Linux/WSL only and 24 GB recommended → does not suit the project. Remains **only as an isolated WSL experiment** (decision #15). |
| TTS | **Trendyol-TTS** as **primary** on the live pipeline | TR native and intelligible (round-trip WER ~0.08) **but** ~5.6 GB VRAM + RTF ~3 → it does not fit on an 8 GB card with a resident 9B LLM and it misses the `<1 s` target. **Adopted as the offline/high-quality engine** (decision #16); not suitable for the live pipeline |
| TTS | **CosyVoice2**, **XTTS-v2** | Turkish-capable but slow on GPU/CPU; risky in the live `<1 s` pipeline (backup candidates, decision #16) |
| TTS | **Kokoro-82M** | Does not support Turkish |
| TTS | **F5-TTS** | English/Chinese only |
| TTS | **XTTS-v2** | Older; non-commercial license + slow on CPU (Chatterbox v3 is newer and more natural) |
